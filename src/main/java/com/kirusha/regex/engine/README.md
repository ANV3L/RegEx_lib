# Engine (Движок матчинга)

## Ответственность
Пакет `engine` отвечает за:
1. Проверку соответствия строки регулярному выражению (операция `match`);
2. Матчинг через DFA (без групп захвата — быстрый путь);
3. Матчинг через NFA (с поддержкой групп захвата);
4. Предоставление результата матчинга с доступом к группам захвата.

---

## Контракт

### Input
- `DFA` или `NFA` — скомпилированный автомат;
- `String input` — строка для проверки.

### Output
`MatchResult` — результат проверки.

Содержит:
- `boolean matches` — результат проверки;
- `List<String> groups` — захваченные подстроки (для NFA engine);
- доступ к группам через итератор и оператор индексации.

---

## Основные сущности

### MatchResult
Результат матчинга.

Интерфейс:
- `boolean matches()` — совпало ли;
- `String group(int index)` — получить содержимое группы по номеру;
- `int groupCount()` — количество групп;
- `Iterator<String>` — перебор групп через итератор.

### DFAEngine
Матчинг строки через DFA.

Алгоритм:
1. Начать с startState;
2. Для каждого символа входной строки перейти по transition;
3. Если в конце оказались в acceptState → match.

Особенности:
- Линейное время O(n);
- Не поддерживает группы захвата.

### NFAEngine
Матчинг строки через NFA с поддержкой групп захвата.

Алгоритм:
- Симуляция NFA с отслеживанием множества текущих состояний;
- Запись начала/конца каждой группы захвата;
- Может использовать backtracking для групп.

Особенности:
- Поддерживает группы захвата;
- Используется, когда в regex есть `(...)`.

---

## Стратегия выбора движка
- Если regex содержит группы захвата → NFAEngine;
- Если regex без групп захвата → DFAEngine (оптимальный путь).

---

## Замечания
1. Перегрузка `match`:
   - `match(String input)` → `boolean` (без групп);
   - `match(String input)` → `MatchResult` (с группами).
2. MatchResult должен поддерживать Iterator для перебора групп.
