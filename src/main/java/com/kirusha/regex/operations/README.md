# Operations (Операции над автоматами)

## Ответственность
Пакет `operations` отвечает за теоретико-множественные операции над языками,
представленными как DFA:

1. **Пересечение** (intersection) — L(A) ∩ L(B);
2. **Разность** (difference) — L(A) \ L(B);
3. **Объединение** (union) — L(A) ∪ L(B);
4. **Дополнение** (complement) — Σ* \ L(A);
5. **Инверсия** (inversion) — разворот всех строк языка;
6. **Проверка изоморфизма** двух DFA.

---

## Контракт

### Input
- Один или два объекта `DFA` (в зависимости от операции).

### Output
- Новый объект `DFA`, не изменяя исходные автоматы.

---

## Основные сущности

### DFAOperations
Статические методы для бинарных и унарных операций:

- `DFA intersect(DFA a, DFA b)` — пересечение;
- `DFA difference(DFA a, DFA b)` — разность (a \ b);
- `DFA union(DFA a, DFA b)` — объединение;
- `DFA complement(DFA a)` — дополнение;
- `DFA invert(DFA a)` — инверсия (reverse).

Бинарные операции реализуются через product construction:
1. Состояния нового автомата = пары (q_a, q_b);
2. Переходы по алфавиту union(Σ_a, Σ_b);
3. Принимающие состояния зависят от операции:
   - intersection: оба принимающие;
   - difference: q_a принимающее, q_b нет;
   - union: хотя бы одно принимающее.

Complement:
- Инвертировать accept/reject для полного DFA.

Inversion:
- Развернуть все переходы;
- Создать новый start = бывшие accept states (через NFA с epsilon);
- Accept = бывший start.

### DFAIsomorphism
Проверка двух DFA на изоморфизм:
- Обход графа переходов с сопоставлением состояний;
- Используется для тестирования операций.

---

## Важные свойства
1. Все операции **не мутируют** исходные автоматы;
2. Результат операции — полноправный DFA, пригодный для дальнейших операций;
3. Операции игнорируют группы захвата;
4. Перед операциями DFA должен быть **полным** (dead state для отсутствующих переходов).
