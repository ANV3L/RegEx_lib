# DFA (Детерминированный конечный автомат)

## Ответственность
Пакет `dfa` отвечает за:
1. Представление детерминированного конечного автомата в памяти;
2. Преобразование NFA → DFA методом подмножеств (subset construction);
3. Минимизацию DFA (алгоритм Хопкрофта);
4. Передачу результата в engine для матчинга и в operations для операций над автоматами.

---

## Контракт

### Input
`NFA` — недетерминированный конечный автомат, построенный `ThompsonBuilder`.

Содержит:
- `NFAState startState` — стартовое состояние;
- `NFAState acceptState` — принимающее состояние;
- `Set<NFAState> states` — множество всех состояний;
- `Set<String> alphabet` — алфавит автомата.

### Output
`DFA` — минимальный детерминированный конечный автомат.

Содержит:
- стартовое состояние;
- множество принимающих состояний;
- все состояния;
- алфавит;
- детерминированные переходы: `state + symbol → state`.

---

## Основные сущности

### DFAState
Состояние ДКА.

Хранит:
- уникальный идентификатор;
- переходы по символам (`Map<String, DFAState>`);
- флаг принимающего состояния.

### DFA
Полный объект детерминированного автомата.

Хранит:
- startState;
- acceptStates;
- все состояния;
- алфавит.

### SubsetConstructor
Преобразует NFA в DFA методом подмножеств.

Алгоритм:
1. Вычислить epsilon-closure стартового состояния NFA → начальное состояние DFA;
2. Для каждого нового состояния DFA и каждого символа алфавита вычислить move + epsilon-closure;
3. Повторять, пока не будут обработаны все состояния.

### DFAMinimizer
Минимизирует DFA алгоритмом Хопкрофта.

Алгоритм:
1. Разбить состояния на два класса: принимающие и непринимающие;
2. Итеративно разбивать классы по переходам;
3. Построить новый DFA из классов эквивалентности.

---

## Конвейер
```
NFA → SubsetConstructor → DFA → DFAMinimizer → минимальный DFA
```

---

## Ограничения и замечания
1. DFA переходы детерминированы: из каждого состояния по каждому символу ровно один переход.
2. Операции над автоматами (пересечение, разность и т.д.) выполняются на уровне DFA.
3. Группы захвата на уровне DFA не поддерживаются — для них используется NFA engine.
4. Результатом subset construction может быть экспоненциально большой автомат, минимизация обязательна.
