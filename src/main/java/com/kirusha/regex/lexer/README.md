# Lexer (Лексический анализатор)

## Ответственность
Первый этап конвейера. Преобразует сырую строку регулярного выражения
в упорядоченный список токенов. Обрабатывает экранирование метасимволов.

## Контракт

### Input
`String regex` — строка регулярного выражения из `Regex.java`

Пример: `(a|b)*c{3}[xyz]#`

### Output
`LexerResult` — объект-отчёт, содержащий:
- `List<Token> tokens` — список распознанных токенов
- `String originalInput` — исходная строка (для отладки и сообщений об ошибках)

### Ошибки
При некорректном вводе (например, `\` в конце строки без символа после него)
выбрасывается `LexerException` с указанием позиции ошибки.

## Метасимволы
| Символ | Токен       | Описание                              |
|--------|-------------|---------------------------------------|
| `\|`   | PIPE        | Операция "или"                        |
| `*`    | STAR        | Замыкание Клини                       |
| `(`    | LPAREN      | Открывающая скобка                    |
| `)`    | RPAREN      | Закрывающая скобка                    |
| `[`    | LBRACKET    | Начало набора символов                |
| `]`    | RBRACKET    | Конец набора символов                 |
| `{`    | LBRACE      | Начало повтора                        |
| `}`    | RBRACE      | Конец повтора                         |
| `#`    | EPSILON     | Пустая подстрока                      |
| `\`    | —           | Экранирование или ссылка на группу    |

## Правила экранирования
- `\` + метасимвол → `CHAR` (экранирование: `\*` это символ `*`)
- `\` + цифра(1-9) → `BACKREF` (ссылка на группу захвата)
- `\` + конец строки → `LexerException`

## Пример
Вход: `(a|b)*`
Выход: `[LPAREN, CHAR(a), PIPE, CHAR(b), RPAREN, STAR]`
